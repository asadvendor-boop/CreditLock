# CreditLock Claim-to-Evidence Matrix

This document provides a strict, audit-verifiable matrix mapping every submission claim to its supporting evidence, exact code/infrastructure location, evidence classification, scope of proof, non-proof boundaries, and public admissibility status.

## Classification Legend

- `HOSTED_VERIFIED`: Verified directly on the live Cloud Run production instance (`https://creditlock-fvyx7hpwvq-uc.a.run.app` revision `creditlock-00027-jeh`).
- `RECORDED_LIVE`: Recorded live against an external cloud service (e.g. Confluent Cloud Kafka cluster on partition 0).
- `EMULATOR_VERIFIED`: Verified against local cloud software emulators (e.g. Firestore emulator).
- `VERIFIED_LOCAL`: Verified in local test/eval execution suite (`pytest` or local evaluation scripts).
- `HISTORICAL_EVIDENCE`: Historical/adjudicated run logs or benchmark records from prior commits (e.g. Frozen V2). Not valid as final HEAD code quality metrics.
- `UNVERIFIED`: Functionality or resource not yet verified or active in the current deployment.
- `NOT_CLAIMED`: Explicitly out of scope; explicitly excluded from submission claims.
